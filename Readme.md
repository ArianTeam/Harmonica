# آموزش هارمونیکا و مستندات هارمونیک CMS

این پروژه مجموعه‌ای از مستندات و آموزش‌های مربوط به **هارمونیک CMS** و تگ‌های قالب‌گذاری آن است.  
هدف این مستندات، توضیح ساختار تگ‌ها، نحوه استفاده در UI، و منطق پردازش هر بخش در سمت backend است تا توسعه‌دهندگان بتوانند راحت‌تر با سیستم کار کنند.

---

## درباره پروژه

این مجموعه برای معرفی و مستندسازی بخش‌های مختلف هارمونیک CMS تهیه شده و شامل توضیح کامل تگ‌ها و متدهای پردازش محتوا است؛ از جمله:

- `feedback`
- `datagroup`
- `relatedcontent`
- `chart`
- `form`
- `banner`
- `itempoll`
- `contentsubgroup`

این مستندات به تیم‌های فنی و UI کمک می‌کند تا بتوانند قالب‌ها را به‌درستی پیاده‌سازی کنند و منطق تولید محتوا را بهتر درک کنند.

---

## نمونه مستندات موجود

در این بخش، نمونه‌هایی از منطق یکی از تگ‌ها مانند `relatedcontent` توضیح داده می‌شود:

### `relatedcontent`
این متد برای نمایش **محتوای مشابه / مطالب مرتبط** استفاده می‌شود.  
بر اساس صفحه فعلی، گروه محتوایی مطلب را پیدا می‌کند و چند مطلب دیگر از همان گروه را داخل قالب UI تکرار می‌کند.

#### ویژگی‌ها
- استخراج تعداد آیتم‌ها با `count="N"`
- پیدا کردن `groupid` از مطلب فعلی
- دریافت مطالب منتشرشده و فعال از همان گروه
- رندر template داخلی برای هر آیتم
- جایگزینی placeholderها با داده‌های واقعی

## نکات مهم

- فقط از `double quote` برای attributeها استفاده شود.
- `relatedcontent` نباید به‌صورت nested استفاده شود.
- فیلد `editor` به‌صورت HTML خام تزریق می‌شود.
- اگر `request.Id = 0` باشد، گروه مطلب فعلی قابل تشخیص نیست.
- مطالبی که زمان انتشارشان نرسیده باشد، نمایش داده نمی‌شوند.

## کاربرد در UI

این سیستم برای ساخت UIهای زیر بسیار مناسب است:

- کارت مقاله
- لیست خبر
- اسلایدر مطالب مشابه
- grid محتوا
- لیست گروهی مطالب
